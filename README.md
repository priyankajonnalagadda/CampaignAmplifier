# amplify. — Campaign Amplification App 📣

**Discover causes. Create campaigns. Amplify messages that matter.**

amplify. is a React Native mobile application built with Expo for the Humanity Founders Campaign Amplification Hackathon. It helps users explore meaningful causes, create campaigns, and support initiatives that deserve greater visibility.

## ✨ Features

- **Campaign Discovery** — Explore campaigns across health, education, environment, and community.
- **5-Step Campaign Creation** — Create campaigns through Basics, Story, Visuals, Reach, and Review.
- **Campaign Details** — View campaign stories, target audiences, expected impact, goals, and progress.
- **Simulated Support** — Demonstrate campaign contributions through an interactive support flow.
- **Activity Dashboard** — View campaign-related activity.
- **Profile & Statistics** — Explore campaign counts and demo statistics.
- **Mobile-First UI** — Clean interface with bottom-tab navigation.

## 🛠️ Tech Stack

- React Native
- Expo
- JavaScript
- React Navigation
- AsyncStorage (local persistence, if enabled in the current build)

## 🚀 Run Locally

```bash
git clone https://github.com/priyankajonnalagadda/CampaignAmplifier.git
cd CampaignAmplifier
npm install
npx expo start
```

Follow the Expo instructions to run the app on a compatible Android device or emulator.

## 📱 Android APK

An Android APK was generated using **Expo Application Services (EAS Build)** for installation and testing on compatible Android devices.

## ⚠️ Demo Notice

This is a hackathon prototype. Contributions are simulated; no real payments are processed, and no actual social media promotion occurs.

## 🎯 Purpose

To make it easier for people to discover meaningful causes, share their stories, and support campaigns that can inspire positive change.
